Literature Review Agent — Project Plan
Goal: A multi-agent system that helps CS/ML researchers conduct a preliminary literature review. 

Input: Keywords or seed paper
Output: List of relevant papers (ranked) + literature review that summarizes main ideas and highlights limitations and gaps in current literatures. 

Features:


Data Sources:
- Semantic scholar: search, recommendations, citation and reference search, can use SPECTER2 embeddings for similarity score
- arXiv API: monitoring, find papers that were published recently (semantic scholar is delayed by days/1-2 weeks)
- Google scholar --> scraping would be difficult
